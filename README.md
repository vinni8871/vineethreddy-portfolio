# Vineeth Kumar Reddy — Portfolio

My personal portfolio website built with React, TypeScript, and Tailwind CSS.

🔗 **Live:** [vinni8871.github.io/vineethreddy-portfolio](https://vinni8871.github.io/vineethreddy-portfolio/)

## Tech Used

- React 19 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion

## Run Locally

```bash
npm install
npm run dev
```

Opens at http://localhost:5173

## Build

```bash
npm run build
```

## Update Content

All portfolio content (skills, projects, experience, etc.) is in `src/data.ts` — edit that file to update the site.

Images and resume go in the `public/` folder.
